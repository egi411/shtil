# Штиль — демо «одна сцена моря под всей страницей»

Одностраничный концепт для аренды яхт с капитаном, четыре блока:

1. **Закат** — слово-силуэт стоит на линии горизонта и отражается в воде, курсор пускает рябь
2. **Ночь** — фраза загорается по словам, фото летят навстречу из глубины
3. **Флот** — светлый лист с тремя полосами-аккордеоном
4. **Рассвет** — то же море светлеет, форма заявки

- Один файл `index.html`: сырой WebGL2, GSAP и Lenis с CDN, фото по ссылкам Unsplash
- Текст остаётся в DOM; без WebGL или при `prefers-reduced-motion` — статичное фото
- Названия яхт и цифры условные, форма никуда не отправляет данные

Открыть: `index.html` в браузере (нужен интернет для шрифтов, библиотек и фото). Кадры — в `preview/`.
